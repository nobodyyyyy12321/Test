## 註冊與登入

### 註冊新帳號

1. 點擊右上角（或手機右下方）的「登入 / 註冊」進入登入頁
2. 切換到「註冊」分頁，填寫：
   - **名稱**：你的顯示名稱，會出現在個人頁網址（例如 `/你的名稱`）
   - **Email**：用來登入與接收驗證信
   - **密碼**
3. 送出後系統會寄出驗證信，請到信箱點擊驗證連結完成註冊
4. 若沒有設定郵件服務，畫面會直接顯示驗證連結，點擊即可

### 登入

- 輸入 Email 與密碼即可登入
- 若提示「請點擊驗證信連結」，表示尚未完成 email 驗證
  - 可在登入頁點擊「重新寄送驗證信」按鈕

### 登出

- 桌面版：右上角頭像選單 → 登出
- 手機版：右下角底部選單 → 登出

## 首頁導覽

首頁是整個網站的入口，主要分為幾個區塊：

### 1. 分類書架

- 中央區域以「資料夾」與「項目」呈現所有可練習的分類
- 📁 金色資料夾：點擊可展開／收合下層內容
- 灰白色項目：點擊直接進入該分類的測驗

### 2. 搜尋列

- 頂端搜尋列可同時搜尋：
  - **分類名稱**（例如「英文單字」）
  - **使用者名稱**（搜到對應的個人頁）
- 輸入後會自動展開符合條件的資料夾

### 3. 釘選列（需登入）

- 在首頁分類書架上**拖曳**任何項目（資料夾、測驗、清單、收藏、個人頁分頁）到頂端的「釘選區」
- 釘選後，下次造訪首頁可一鍵展開常用內容
- 想取消釘選：把釘選列裡的項目**拖出**到釘選區外即可

> 提示：手機板需要長按項目約 0.2 秒後再拖曳。

### 4. 語言選擇

- 首頁有「語言選擇器」可切換內容語言（繁中／簡中／英文等）
- 切換後分類與測驗內容會自動載入對應語言版本

### 5. 推薦帳號

- 已登入的使用者，在首頁會看到「推薦的創作者」區塊
- 點擊頭像可進入該使用者的個人頁，瀏覽他們公開的測驗與清單

## 背誦練習

### 進入背誦模式

- 點擊任一葉子節點（灰白色項目）即可進入測驗頁，預設為背誦／練習模式
- 也可從首頁的「背東西」入口進入背誦分類選單

### 練習流程

1. 系統會依分類隨機（或依序）出題
2. 輸入答案後送出，會立即顯示對錯與正確答案
3. 答錯的題目通常會再次出現，幫助加強記憶

### 切換語言版本

- 若該題庫有多語版本，可在頁面切換顯示語言

## 測驗功能

### 開始一場測驗

- 從首頁分類書架點擊測驗項目，網址會是 `/test/<測驗ID>`
- 部分測驗支援額外參數：
  - `?count=20`：指定本次測驗題數
  - `?shuffle=true`：隨機出題順序（預設為固定順序）
  - `?levels=1,2,3`：只練習指定層級

### 測驗中的操作

- 依題型輸入或選擇答案
- 可中途離開，紀錄會自動保存
- 完成後可看到本次的對錯統計

### 查看歷史紀錄

- 個人頁 → 「紀錄」分頁，可看到過往所有測驗成績
- 點擊紀錄可重播該次測驗

## 清單與收藏

清單（List）和收藏（Collection）是兩種整理題目的方式：

### 個人清單（Lists）

- 自己手動建立的題目組合，適合**整理特定範圍**（例如「期末複習」）
- 進入個人頁 → 「清單」分頁建立新清單
- 點擊清單名稱進入編輯頁面：
  - 可手動新增、刪除題目
  - 可調整題目順序
  - 可設定為公開或私人

### 收藏（Collections）

- 將整個分類加入收藏，方便快速練習
- 在分類書架上右鍵（或長按）任何項目 → 「加入收藏」
- 收藏會出現在個人頁「清單」分頁的「我的收藏」區
- 收藏可整理到資料夾，並設定每次抽幾題、是否打亂順序

### 資料夾整理

- 在「清單」分頁可建立資料夾
- 把清單或收藏**拖曳**到資料夾中分類管理

## 個人頁與社交

每個使用者都有一個專屬個人頁，網址是 `/<使用者名稱>`。

### 個人頁分頁

進入自己的個人頁後，會看到下列分頁：

| 分頁 | 用途 |
|------|------|
| 個人資料 | 顯示頭像、簡介、社群連結 |
| 清單 | 我建立的所有清單與收藏 |
| 紀錄 | 我的測驗歷史紀錄 |
| 追蹤者 / 追蹤中 | 社交關係 |
| 群組 | 我建立或加入的群組 |
| 已封鎖 | 我封鎖的使用者 |
| 圖庫 | 我上傳的圖片資源 |
| 派發（寄出） | 我指派給別人的測驗 |
| 派發（收到） | 別人指派給我的測驗 |
| 設定 | 個人資料、密碼、社群連結等設定 |
| 上傳 | 上傳新的題目／圖片 |

### 編輯個人資料

- 個人頁 → 「設定」分頁
- 可修改：
  - 頭像、暱稱、簡介
  - 社群連結（X、Facebook、Instagram、Threads、個人網站）
  - 密碼

### 追蹤其他使用者

- 進入對方的個人頁，點擊「追蹤」按鈕
- 雙方可在「追蹤中」與「追蹤者」分頁查看關係

### 指派測驗（Assignment）

幫他人安排限時測驗：

1. 在對方個人頁或測驗頁，選擇「指派」
2. 設定：
   - 標題
   - 開始時間、結束時間
   - 要指派的題目範圍
3. 對方會在自己的「派發（收到）」分頁看到該測驗
4. 完成後成績會自動回傳給指派者，顯示於「派發（寄出）」分頁

### 群組

- 可建立群組，邀請其他使用者加入
- 適合一次指派測驗給多位成員（例如班級、讀書會）

### 釘選個人頁分頁

- 在個人頁分頁上右鍵（或長按） → 釘選
- 釘選後該分頁會出現在首頁釘選列，方便快速進入

## 手機操作

網站對手機與平板做了專門優化：

### 底部導覽列

手機版底部固定有四個按鈕：

- 🏠 **首頁**
- 📤 **分享**：分享目前頁面連結
- ⚙️ **設定**（需登入）：主題、語言等
- 👤 **登入／個人頁**

### 邊緣滑動

- **從右邊緣往左滑**：快速跳到自己的個人頁（未登入則跳到登入頁）
- 個人頁中可**左右滑動切換分頁**

### 下拉刷新

- 在頁面頂端**下拉**可刷新內容（與原生 App 體驗一致）

### 安裝為 App（PWA）

- 在支援的瀏覽器中，會出現「安裝 App」按鈕
- 安裝後可從手機桌面直接開啟，享受全螢幕體驗

### 螢幕方向提示

- 部分頁面建議橫向觀看，系統會自動顯示提示

### 長按拖曳

- 釘選、清單整理等拖曳操作，在手機上需**長按約 0.2 秒**後再開始拖曳

## 其他常用設定

### 主題切換

- 設定選單可在「淺色 / 深色 / 跟隨系統」之間切換
- 設定會自動記憶到本機

### 語言切換

- 首頁的語言選擇器與設定選單均可切換介面語言
- 切換後分類資料會重新載入

### 計時器

- 部分頁面右上角有計時器按鈕，方便記錄練習時間

### 音樂提示（Music Tip）

- 練習時可開啟背景音樂或專注提示音
- 在頁面相關按鈕中啟用

### 上傳題庫／圖片

- 個人頁 → 「上傳」分頁可上傳：
  - 新的題目集
  - 圖片資源（會出現在個人頁的「圖庫」）
- 上傳的內容預設為私人，可在編輯頁面切換為公開

### 回報問題

- 進入 `/feedback` 頁面送出意見或問題回報

## 常見問題

**Q：忘記密碼怎麼辦？**
A：請從登入頁的「忘記密碼」流程重新設定（或聯絡管理員）。

**Q：為什麼登入後找不到我建立的清單？**
A：確認你是否登入到正確的帳號（右上角頭像）。清單只在登入的擁有者帳號下可見。

**Q：手機上拖曳沒反應？**
A：手機需要**長按約 0.2 秒**後再開始拖曳，這是為了避免誤觸。

**Q：為什麼測驗中途離開，回來進度不見？**
A：進度會在每次答題後保存，若仍遺失請檢查網路連線是否中斷。

**Q：如何取消對某人的追蹤？**
A：進入對方個人頁，再次點擊「追蹤中」按鈕即可取消。
